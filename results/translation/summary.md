# Issue 24 EN-PT low-rank rescue summary

## Objective

Issue #24 asks for the minimum LoRA/rsLoRA rank that rescues English -> Portuguese translation in `tencent/HY-MT1.5-1.8B` when the model is forced through a fixed MLP-channel mean-ablation lesion.

This is not a standalone-compression claim. The dense base model still exists. The measured claim is narrower: under fixed lesion `L_k`, a low-rank adapter can restore much of the behavior lost by the lesion.

## Setup

- Model: `tencent/HY-MT1.5-1.8B`
- Train/calibration rows: 1,012 FLORES EN->PT teacher hypotheses generated by unmasked HY-MT
- Held-out eval rows: 1,012 NTREX EN->PT rows
- Lesion: fixed ReLP MLP-channel mask plus mean ablation at MLP `down_proj` input
- Mask budgets: `k=80000`, `k=120000`, `k=160000`
- Main rank sweep: `k=120000`, ranks 4, 8, 16, 32, 64
- Expansion: `k=160000` ranks 16 and 32; `k=80000` ranks 16, 32, and 64
- Decode: greedy generation, `max_new_tokens=384`

`Unbabel/XCOMET-XXL` was blocked by gated Hugging Face access, and GEMBA-MQM credentials were unavailable. The run therefore uses chrF++/chrF/BLEU plus accessible COMET-22 fallback (`Unbabel/wmt22-comet-da`). The XCOMET block is infrastructure, not a science failure.

## Main k=120k Result

| rank | no-mask chrF++ | masked chrF++ | masked BLEU | no-mask COMET-22 | masked COMET-22 |
| --- | ---: | ---: | ---: | ---: | ---: |
| base | 54.259 | 26.664 | 3.844 | 0.8650 | 0.5693 |
| 4 | 54.302 | 38.971 | 10.366 | 0.8629 | 0.5650 |
| 8 | 54.058 | 40.557 | 12.297 | 0.8627 | 0.6024 |
| 16 | 53.970 | 42.437 | 14.309 | 0.8627 | 0.6424 |
| 32 anchor | 53.372 | 43.727 | 14.904 | 0.8557 | 0.6668 |
| 64 | 51.185 | 43.455 | 14.881 | 0.8280 | 0.6665 |

The lesion is real: base HY-MT drops from 54.259 chrF++ / 0.8650 COMET-22 without masking to 26.664 chrF++ / 0.5693 COMET-22 under `L_120k`.

Fresh target-90 thresholds:

- chrF++ target: `26.6635 + 0.9 * (43.7270 - 26.6635) = 42.0206`
- COMET-22 target: `0.5693 + 0.9 * (0.6668 - 0.5693) = 0.6571`

Rank 16 is the first chrF++ pass, but it misses the COMET-22 threshold. Rank 32 is the first conservative pass. Rank 64 matches rank 32 under the mask but degrades no-mask behavior.

Conclusion for the main setting: the conservative rank floor is **r=32** under COMET-22 fallback; the cheap-metric floor is **r=16**.

The easier `k=160k` lesion is already handled by rank 16, which beats rank 32 on masked chrF++. The harder `k=80k` lesion benefits from rank 32, while rank 64 again fails to buy a cleaner rescue and hurts no-mask behavior.

COMET-22 expansion baselines were also scored for base masks: base `k=80k` = 0.4140; base `k=160k` = 0.7013. Rank COMET for expansion was not needed for the #24 closing decision because the main rank floor is defined at `k=120k`.

## Controls

| condition | masked chrF++ | masked BLEU | COMET-22 | read |
| --- | ---: | ---: | ---: | --- |
| base + k=120k | 26.664 | 3.844 | 0.5693 | lesion baseline |
| zero-update r32 + k=120k | 26.528 | 3.707 | 0.5681 | no rescue |
| no-lesion self-distill r32 + k=120k | 22.260 | 1.823 | 0.5079 | no rescue |
| shuffled-target r32 + k=120k | 36.081 | 11.166 | 0.6253 | partial lift, below threshold |
| true masked-rescue r32 + k=120k | 43.727 | 14.904 | 0.6668 | conservative pass |

The zero-update and no-lesion controls fail cleanly. The shuffled-target control gives some cheap-metric lift, but it remains below the COMET-22 target-90 threshold of 0.6571 and below the true rank-32 rescue by 0.0415 COMET-22 and 7.65 chrF++.

## Qualitative Audit

Sampled rows `0`, `3`, `10`, `25`, and `100` from the held-out dumps.

- Base `k=120k` frequently mixes English with malformed Portuguese, for example row 25 keeps "said" and "the disappearance" in English.
- Rank 16 and rank 32 restore Portuguese sentence form and much more of the source content, but still show lexical artifacts like awkward named-entity handling and non-native morphology.
- Rank 64 sometimes drifts semantically despite similar masked scores, matching the no-mask degradation signal.
- No-lesion self-distill leaves source-copying behavior under the lesion, supporting that ordinary distillation is not the rescue mechanism.
- Shuffled-target training can improve surface fluency but overgeneralizes or adds unrelated content, matching its below-threshold COMET-22 score.

## Closing Conclusion

Issue #24 has a positive result. EN->PT translation in HY-MT is sufficient-rescuable under fixed mean-ablation lesion `L_120k` by a rank-32 LoRA/rsLoRA adapter according to NTREX COMET-22 fallback. Rank 16 is the cheap-metric floor but not the conservative COMET floor. Higher rank does not improve the result and damages normal no-mask behavior.

This is enough to close #24. The downstream standalone low-rank experiment in #25 should use rank 32 as the first serious compiler target, with rank 16 kept as the aggressive lower-bound attempt.
